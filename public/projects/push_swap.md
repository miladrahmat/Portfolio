### Tech Stack: C

### Overview

This project is program that **sorts a stack of integers** by using the **minimal amount of actions** using a second stack to store the sorted integers.

For this problem the algorithm that I implemented was [The Turk Algorithm](https://medium.com/@ayogun/push-swap-c1f5d2d41e97), which was the most efficient solution for this specific project.

### What I learned

During this project I learned the **basics of algorithms** and **data structures** and how to utilize them in the C language.
