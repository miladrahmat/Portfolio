### Tech Stack: C, Computer Graphics

### Overview

This project is a wireframe renderer that converts a 2D map file into a 3D representation, with the goal of introducing me into **Computer Graphics**, especially **rendering and transformations**

### What I learned

During this project I learned the basics of computer graphics utilizing [MLX42](https://github.com/codam-coding-college/MLX42) with the challenge of implementing **trigonometry** in C. How to **visualize user events** and create a **clear UI**.
