### Tech Stack: C++

### Overview

This **team project** is an **Internet Relay Chat (IRC) server** with essential features and multiple client connections.

### What is IRC

An Internet Relay Chat or IRC is a text-based communication protocol on the internet, It offers real-time messaging that can be either public or private.

### What I did

This project was built in a team of 3 people, where we all took responsibility of implementing cerain features for the project.

The features I implemented were:
- **Command parsing**
- **Multiple clients** support (**TCP Sockets**)
- **Nickname change** support
- **Private messages** between users
- **Authentication** vie password

The features my teammates implemented were:
- **Channels** with **topic** management
- **Channel operator and administrative** privileges
- **Channel modes** (invite only, topic restictions, etc.)
- **Kicking** users from channels
- **Invitations** to private channels
- **WHO command** for listing channel users
- **File transfer** between users

Since this project was implemented in **C++**, I learned to build a server using **OOP** (Object Oriented Programming), all while streghtening my **teamwoking** and **time management** skills.
